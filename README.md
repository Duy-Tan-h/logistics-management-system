# Logistics Management System

Dự án nhóm website logistics: yêu cầu báo giá, quản lý đơn, phân xe/tài xế, chuyến vận chuyển và tra cứu hành trình.

## Công nghệ

C#, ASP.NET Core MVC .NET 8, Entity Framework Core, SQL Server, HTML/CSS/JavaScript.

## Chạy tại máy

.NET 8 SDK và SQL Server. Cấu hình ConnectionStrings trong appsettings.json cho máy của bạn, chạy `dotnet restore`, `dotnet ef database update`, sau đó `dotnet run`. Kiểm tra cấu hình và dữ liệu khởi tạo trong Program.cs trước khi chạy.

Cấu hình mật khẩu được thay bằng giá trị mẫu. Thư mục build và thư viện đã biên dịch không được đưa vào repo. Đây là mã nguồn dự án học tập theo nhóm; mô tả chức năng không ngụ ý một thành viên thực hiện toàn bộ.
